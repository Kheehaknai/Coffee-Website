# ☕ Coffee Shop Website - Frontend Project

A clean and modern responsive coffee shop website designed to provide an elegant user experience. This project focuses on a "Minimalist & Warm" aesthetic, perfect for a digital cafe presence.

## 🚀 Key Features

* **Responsive Layout:** Fully optimized for mobile, tablet, and desktop screens.
* **Modern Navigation:** Smooth transitions and intuitive menu structure.
* **Product Showcase:** Visual-first approach to displaying coffee beans and bakery items.
* **Interactive UI:** Hover effects and animations to enhance user engagement.

## 🛠️ Tech Stack

* **HTML5:** Semantic markup for better accessibility and SEO.
* **CSS3:** Custom Flexbox and Grid layouts for precise positioning.
* **JavaScript:** Handling basic interactivity and UI logic.

## 🎨 Design Concept

The UI is built around a "Cafe Cozy" theme, using warm earth tones and high-quality imagery to evoke the feeling of a premium coffee shop.

## 📂 Project Structure

* `index.html` - The main landing page.
* `style.css` - Custom styling and layout system.
* `script.js` - Basic interactive features.
